# 中国移动10086浏览器加载项

启动加载项后，在 Home Assistant 添加“中国移动10086”集成：输入手机号，收到短信后在集成第二步输入验证码。加载项内的浏览器会每 30 分钟查询一次；若集成显示 `login_required`，在集成卡片点“重新认证”。“打开界面”提供远程浏览器，供官方网页要求滑块等额外验证时使用。

此加载项只访问 `wx.10086.cn` 进行只读查询。每个账号使用独立且持续运行的持久化浏览器配置，按账号轮流查询。远程界面显示当前正在登录或查询的账号；进行短信登录时会暂缓其他账号的查询，避免把页面切走。多个账号会增加 HAOS 内存占用。共享给 HA 集成的 `/share/china_mobile_10086/accounts/` 结果文件只含数值、更新时间和状态，不含手机号或验证码。旧版单账号配置保留在 `/data/browser_profile`。

网页出现“点击刷新”时会自动点击；已有字段仍不完整时会重新加载网页，最多尝试三次。查询失败后每 5 分钟重试，成功后恢复 30 分钟查询间隔。登录失效仍需重新认证。
