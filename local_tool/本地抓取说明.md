# 本地抓取中国移动10086只读请求

下载并完整解压发布包 `china_mobile_10086-local-capture.zip`，双击其中的 `获取10086请求.cmd`。工具会启动本机 mitmproxy，监听 **8082** 端口，最长等待 15 分钟；仅保存 `wx.10086.cn` 的话费、流量、通话三个只读 GET 请求。请求在 `%LOCALAPPDATA%\ChinaMobileHA\capture.dpapi` 中以当前 Windows 用户的 DPAPI 加密保存，不记录响应内容，不打印 Cookie 或手机号。

1. 保持电脑移动热点开启，让 iPhone 连上此热点。若 iPhone 分到 `192.168.137.x`，电脑代理地址通常是 `192.168.137.1`。
2. 在 iPhone 当前 Wi-Fi 的“配置代理”选择手动，服务器填电脑热点地址，端口填 **8082**，认证关闭。
3. 首次使用时，等代理启动后用 Safari 打开 `http://mitm.it`，选择 iOS 下载证书描述文件；到 iPhone“设置 → 通用 → VPN 与设备管理”安装，再到“设置 → 通用 → 关于本机 → 证书信任设置”开启 mitmproxy 证书的完全信任。若此前已安装并信任同一台电脑的 mitmproxy 证书，无需删除或重装。若打不开 `mitm.it`，检查网址是 `http://`、代理地址和端口正确，并稍等代理启动。
4. 在微信“中国移动10086”服务号打开主页并下滑刷新，等待电脑窗口显示“已抓齐三个只读请求”。
5. 把剪贴板内容直接粘贴到 HA 集成的配置页。完成后关闭 iPhone Wi-Fi 代理，并用普通文字覆盖剪贴板。

若已经抓取成功但复制失败，可双击 `复制10086请求.cmd` 重新复制。登录失效后重复抓取。该工具不会自动登录微信，也无法保证服务号 Cookie 的有效期。发布包中的 `bin` 和 `python` 已包含运行时，不依赖奇瑞目录。它与奇瑞工具共用当前 Windows 用户的 mitmproxy 证书，使用独立的 8082 端口和独立的加密保存目录。
